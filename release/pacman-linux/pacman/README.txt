================================================================
  PAC-MAN
  42 school project
================================================================

RUNNING THE GAME
----------------

  From a terminal:      ./pacman
  Or:                   ./run.sh
  Or double-click the "pacman" file from your file manager.

  If the file will not start, make it executable first:

      chmod +x pacman

  The game ships with its own configuration, so no argument is
  needed. To play with your own settings, pass a JSON file:

      ./pacman my_config.json


CONTROLS
--------

  Menus
      Up / Down ............. move the selection
      Enter ................. confirm

  In game
      Arrow keys ............ move Pac-Man
      Z Q S D  or  W A S D .. move Pac-Man
      P  or  Escape ......... pause / resume

  A direction stays in effect until Pac-Man hits a wall, so you can
  press a turn slightly before a junction: it is applied as soon as
  the passage opens up.

  Game over / victory
      Type your name (letters, digits and spaces, 10 characters max)
      Enter ................. save the score and return to the menu


CHEAT MODE
----------

  Meant for the peer review, to reach and test every feature quickly.

      F1 .................... invincibility on / off
      F2 .................... skip the current level
      F3 .................... freeze the ghosts
      F4 .................... add one life
      F5 .................... speed boost on / off

  Active cheats are listed on screen while they are enabled.


THE GAME
--------

  Eat every pacgum in the maze to clear the level. The four larger
  pellets in the corners are super-pacgums: they make the ghosts
  edible for a short while, and eating one is worth extra points.

  Four ghosts start in the four corners and chase you. Touching one
  costs a life; you respawn in the middle of the maze. The game ends
  when you run out of lives, when every level is cleared, or when a
  level's timer runs out.

  The yellow "42" shape in the middle of the maze is part of the
  generated layout. Those cells are walled off on all four sides: no
  one can enter them, and no pacgum is ever placed there.


CONFIGURATION
-------------

  The configuration file is JSON, with comments allowed. Lines
  starting with #, // comments and /* ... */ blocks are all ignored.

  Any missing, invalid or out-of-range value falls back to a safe
  default and prints a message; unknown keys are ignored. The game
  never crashes on a bad configuration file.

  Keys, with their default values:

      highscore_filename   "highscore.json"
          Where scores are saved. Relative to the folder you launch
          the game from.

      levels               [ { "width": 15, "height": 15 } ]
          One entry per level. The list is padded to at least 10
          levels, each slightly larger than the last. Width and
          height are clamped between 5 and 101.

      lives                3        (1 to 99)
      pacgum               42       pacgums per level
      points_per_pacgum    10
      points_per_super_pacgum  50
      points_per_ghost     200
      seed                 42
          Seed for the first level, so it is always the same maze.
          Later levels are always random. A seed of 0 or less makes
          the first level random too.
      level_max_time       90       seconds per level (10 to 3600)

  Example:

      {
          # first two levels, then 8 more are generated
          "levels": [
              { "width": 15, "height": 15 },
              { "width": 21, "height": 21 }
          ],
          "lives": 5,
          "level_max_time": 120
      }


HIGHSCORES
----------

  The top 10 scores are kept in the file named by
  highscore_filename, and shown from the main menu. Names are
  limited to 10 characters, letters, digits and spaces only;
  anything else is stored as UNKNOWN. A missing or damaged score
  file is replaced by an empty list rather than stopping the game.
